# 🧠 Neuro Trade

Panel en vivo del cerebro de un bot de trading en cuenta demo: lo que piensa en
cada vela, sus neuronas, el curso de análisis técnico que está estudiando, su
metacognición, la fiabilidad de sus "expertos", su memoria de patrones y su
diario de aprendizaje.

**Página:** https://arayfrancisco.github.io/neuro-trade/

## Cómo funciona

Esta página no guarda ningún dato. Al abrirla, el navegador se conecta al bot que
corre en el mismo computador (`http://127.0.0.1:8765`). Por eso:

- Solo muestra datos en el PC donde corre el bot.
- El servidor local del bot solo le responde a esta página; cualquier otro sitio
  web queda bloqueado.
- Si el navegador pregunta si la página puede acceder a la red local, hay que
  aceptar.
